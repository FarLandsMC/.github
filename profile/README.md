# FarLands MC

FarLands is a Minecraft 1.21.10 semi-vanilla server with a few added features to make gameplay more fun and enjoyable.

Server Address: **`farlandsmc.net`**

## Plugins

We built several of the plugins that run on the server, each of which
can be found in this organisation:

- [FarLands](https://github.com/FarLandsMC/FarLands) - Server management and player utilities
- [RegionProtection](https://github.com/FarLandsMC/RegionProtection) - Claims and admin regions
- [ChestShops](https://github.com/FarLandsMC/ChestShops) - Public shops for players

## Libraries

We also maintain libraries:

- [ComponentUtils](https://github.com/FarLandsMC/ComponentUtils) - Utilities built on top of Adventure
